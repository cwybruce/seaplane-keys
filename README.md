Seaplane Keys is a golden-hour seaplane cargo game set in the Coral Keys archipelago: fly a seaplane between six islands, pick up cargo on the water, dodge storm cells and bird flocks, thread checkpoint buoys, and deliver every load before the sun goes down. Top-down Canvas 2D with a following camera, fuel and hull management, a five-leg delivery chain, a live minimap, synthesized WebAudio sound, and a best-score save. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — ↑ / W throttle, ← → steer, ↓ / S slow down, P pause, R restart, Enter to fly.
